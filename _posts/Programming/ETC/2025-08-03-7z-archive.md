### 7z 압축하기
7z는 LZMA 및 LZMA2 압축 알고리즘을 사용하는 아카이브 형식으로, sql에서의 `INSERT INTO` 구분과 같은 반복문을 줄이는데 효과적!

1. **Homebrew로 7z 설치하기**
   ```bash
   brew install p7zip
   ```

2. **SQL 파일 압축하기**
   ```bash
   7z a archive.7z *.sql
   7z a -p1234 archive.7z *.sql  # 비밀번호 설정
   ```
